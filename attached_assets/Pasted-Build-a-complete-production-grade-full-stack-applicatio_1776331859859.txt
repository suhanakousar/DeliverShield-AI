Build a complete, production-grade full-stack application called **DeliverShield AI** — an AI-powered parametric income insurance platform for food delivery partners (Swiggy/Zomato).

This is NOT a demo project. It must behave like a real-world application used daily by delivery workers, with authentication, real-time monitoring, subscription, automated payouts, and advanced fraud protection.

---

## 🎯 CORE PRODUCT VISION

Delivery partners depend on daily earnings. External disruptions (rain, heat, floods, curfews) directly reduce their income.

DeliverShield AI provides:

* Real-time disruption detection
* Automated income loss calculation
* Instant wallet credit (payout simulation with real payment flow feel)
* Fraud-resistant system

NO manual claim process.

---

## 💥 AUTOMATED CLAIM & PAYOUT SYSTEM

When disruption is detected:

1. Validate:

   * User has active policy
   * Location matches zone
   * User active recently

2. Calculate loss:
   loss = (daily_income / working_hours) × disruption_hours

3. Create claim record

4. Credit wallet instantly

5. Store transaction

## 🛡️ ADVANCED FRAUD DETECTION SYSTEM (PHASE 3)

Implement multi-layer fraud detection:

1. Multi-Source Validation

   * Weather must match 2 sources (simulate second source)

2. Geo-Fencing

   * User city must match event location

3. Activity Check

   * User active in last 60 minutes

4. Duplicate Claim Protection

   * Unique hash (user_id + event_id)

5. Claim Rate Limiting

   * Max claims per week

6. Cluster Detection

   * Multiple claims in same zone → flag

7. Anomaly Score (AI simulation)
   anomalyScore = random(0–1)
   if > 0.75 → suspicious

If fraud detected:

* Block payout
* Show alert:
  “⚠ Suspicious activity detected”
